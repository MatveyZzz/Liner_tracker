# Liner Tracker

Минималистичное офлайн-приложение для отслеживания учебных треков на React Native + Expo + TypeScript. Все данные сохраняются локально через AsyncStorage; сервер, авторизация и интернет для работы не нужны.

## Возможности

- Создание и редактирование треков с целью, недельным темпом, датой старта, днями занятий и цветом.
- Единицы измерения: часы или темы.
- Запись занятий с датой, количеством и заметкой; удаление записей и треков.
- Прогресс по общей цели, темп за скользящие последние 7 дней, статус и прогноз завершения.
- Гистограмма активности за 8 календарных недель.
- Подсказка о запланированных на сегодня треках, если сегодня ещё нет записи.
- Настройки и полный сброс локальных данных.

## Запуск

Требуется Node.js 22.13 или новее (SDK 58). Проверь версию командой `node -v`. Склонируй репозиторий и перейди в папку проекта:

```bash
git clone https://github.com/MatveyZzz/Liner_tracker.git
cd Liner_tracker
npm install
npx expo install --fix
npx expo-doctor
npx expo start
```

Установи Expo Go на телефон и отсканируй QR-код из терминала или браузера. Для Android можно нажать `a`, для iOS — `i` (для iOS Simulator нужен macOS). Для web: `npx expo start --web`.

Если `npx expo install --fix` обновит зависимости или сообщит о несовпадении версий, дай ему завершить работу. Если Node.js старее 22.13, сначала обнови Node.js, затем удали `node_modules` и `package-lock.json`, повтори `npm install`.

## Решения MVP

- Используется AsyncStorage: объём данных небольшой, отдельная SQL-база для MVP не нужна.
- Дедлайн не добавлен в модель трека, поэтому показывается прогноз от фактического темпа и расчёт темпа, необходимого для достижения цели за следующие 4 недели.
- В недельном статусе «в графике» означает не менее 80% недельной цели, «опережаешь» — не менее 110%, иначе — «отстаёшь».
- Для удобства дата вводится в формате `ГГГГ-ММ-ДД`, без дополнительной библиотеки выбора даты.
- Напоминания реализованы как подсказка внутри приложения; push-уведомлений нет.
